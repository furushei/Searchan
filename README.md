# Searchan

## Overview

A simple tool that opens Google search results for the entered text in your default browser.

![screenshot](docs/screenshot.png)

## Why Searchan?

Searchan is designed to remove friction from quick web searches:

- **Start typing immediately.** No need to wait for a browser to open or a new tab to load — launch Searchan and the input field is already focused.
- **Pairs perfectly with launchers.** Bind it to a keyboard shortcut or a mouse gesture.

## Features

- Open Google search results in the default browser

## Requirements

- Windows 10 or later (64-bit)
- 70MB disk space

## Installation

1. Download ZIP archive from the [latest release page](https://github.com/furushei/Searchan/releases/latest)
2. Extract the files in the ZIP archive to any folder you want

## Usage

1. Launch `Searchan.exe`
2. Enter a search word
3. Click the magnifying glass button or press Enter
